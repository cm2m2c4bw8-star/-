# 小王管理器

一款**仅供个人使用、本地存储、不联网**的王者荣耀账号记录桌面小工具（Windows）。

记录你的每一个王者账号：登录方式、账号、平台、小区、昵称、等级、段位、生日、荣耀水晶抽奖次数、剩余夺宝券、战令皮肤、2券、礼册，以及自定义活动列。

---

## 快速开始

1. **双击 `小王管理器.exe`** 即可运行，无需安装、无需 Python 环境、无需联网。
2. 第一次运行会自动在同目录生成数据文件 `小王管理器数据.json`（空数据）。
3. 使用过程中所有改动**自动保存**，关闭软件或重启电脑数据不丢。

> Windows 首次双击若提示"已保护你的电脑 / 未知发布者"：点 **更多信息 → 仍要运行** 即可（exe 未做数字签名，属正常现象）。

## 功能一览

| 模块 | 说明 |
| --- | --- |
| 账号结构 | 登录方式（QQ / VX）→ 账号 → 平台（安卓 / iOS）→ 小区 → 昵称 |
| 小区信息 | 第几区 + 小区名、昵称、等级（1-30）、段位、生日（仅月日，用于生日福利提醒） |
| 抽奖记录 | 荣耀水晶累计次数、剩余夺宝券；一键 **5 连抽**（水晶 +5、券 -4），支持 ＋1/－1 微调 |
| 福利记录 | 战令免费皮肤、2券（战令 15 级换 2 张夺宝券）、礼册，均按小区独立记录 |
| 大号标记 | **大号是小区级属性**（可多个）：编辑小区勾选「大号」，左侧树"大号"节点金色高亮 |
| 快捷操作 | 双击对勾列直接切换 √/空白；双击标记列打/取消 ★；双击其他单元格编辑 |
| 活动列 | 可自由添加/改名/删除活动列（对勾 / 文本 / 数字 / 日期），每个小区独立记录 |
| 列表定制 | 拖动列头调顺序、拖列头边界调列宽（自动记忆）、双击列名重命名、列设置显示/隐藏 |
| 自动排序 | 账号按添加先后排列、合并显示、组间细横线；组内平台集中（iOS 前/安卓后）→ 大号在前 → 区号升序（可关闭） |
| 界面缩放 | 按住 Ctrl + 滚轮整体缩放右侧表格（字号/行高/列宽等比），左侧目录树不缩放，比例自动记忆 |
| 行底色 | 「底色设置」可开关行底色，自定义 错色 / 对色 / 大号色 三种颜色 |
| 一键重置 | 「新赛季重置」：2券 → 未兑换、战令皮 → 未领、段位 → 清空；「重置礼册」单独一键重置 |
| 筛选搜索 | 筛选下拉（含"只看标记"）选择即自动刷新，另有手动刷新按钮 |
| 界面调节 | 左侧目录树与右侧表格之间可拖动分隔条调宽度，自动记忆 |
| 生日提醒 | 启动时提示今天 / 近 3 天生日的小区 |

## 目录结构

```
小王管理器/
├── 小王管理器.exe      ← 程序本体（双击运行，可单独拷贝给别人）
├── 小王管理器数据.json ← 你的数据（备份 = 复制此文件）
├── 小王管理器.py       ← 源码（开发用，运行时不需要）
├── PRD.md              ← 产品需求文档
└── README.md           ← 本说明
```

## 备份与迁移

- **备份**：复制 `小王管理器数据.json` 即可（建议定期复制一份到别处）。
- **换电脑 / 给别人用你的数据**：把 exe 和 json 放同一目录，打开即用。
- 旧版本数据（早期 v1/v2 格式）首次打开会自动迁移升级，内容不丢。

## 常见问题

**Q：没有 Python 环境能运行吗？**
A：能。exe 已内置 Python 解释器和所有依赖，双击即用。

**Q：提示"未知发布者"？**
A：点"更多信息 → 仍要运行"。exe 未签名，属正常提示。

**Q：数据存在哪里？**
A：exe 同目录的 `小王管理器数据.json`，纯本地，不联网、不上传。

**Q：改坏了数据怎么办？**
A：json 是文本文件，可手动打开修改；或从备份恢复。
